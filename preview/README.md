# Uzmantech Web Portal Preview

Bu klasör, Uzmantech web portalının etkileşimli tasarım prototipidir.

## İçerik
- Cihaz arama (örnek katalog)
- Marka kategorileri
- Dosya merkezi ve filtreler
- Eğitim kartları
- Üyelik paketleri
- Giriş, kayıt ve manuel ödeme bildirim pencereleri

## Önemli
Bu sürüm yalnızca arayüz prototipidir. Gerçek kullanıcı doğrulaması, Supabase bağlantısı, üyelik kontrolü, ödeme kaydı, video oynatma ve dosya indirme servisi bağlı değildir. Ekrandaki cihaz ve dosya kayıtları örnek veridir. Gerçek erişim kontrolü sunucu tarafında yapılmadan dosya linkleri yayınlanmamalıdır.
